## Kurulum

### Gereksinimler

Bu projeyi çalıştırmak için aşağıdaki yazılımların yüklenmiş olması gerekmektedir:

- Python 
- [Framework/Kütüphane Adı] (opsiyonel)
- Diğer yazılımlar veya sistem gereksinimleri burada listelenecek.

### Kurulum Adımları

1. Bu projeyi klonlayın:
   ```bash
   git clone https://github.com/SedanurCeylan/tubitakprojesi.git
   cd tubitakprojesi
   ```
2. Gerekli Python kütüphanelerini yükleyin:
   ```bash
   pip install -r requirements.txt
   ```
3. Veritabanı şablonu repo içinde bulunan veritabanı.sql dosyasında bulunmaktadır.

4. Uygulamayı çalıştırın:
   ```bash
   python main.py
   ```
5. Local sunucunuzda uygulamaya erişim:
   ```
   http://127.0.0.1:5000
   ```
